⚠️ Important

Pour tester l'accès refusé, vous devez être connecté avec un rôle autre que "super". Les utilisateurs avec les rôles "admin" ou "recruiter" verront un message d'erreur et seront redirigés vers le dashboard.

🔒 Protection par rôle implémentée

  • Rôle requis : "super" uniquement
  • Protection : Guard personnalisé (superRoleGuard)
  • Redirection : Vers /dashboard avec message d'erreur
  • Navigation par fragment : /dashboard/entities#users → /dashboard/users

📋 Fonctionnalités de la page Utilisateurs

  • ✅ Affichage des informations essentielles (ID, nom, prénom, pseudo, email, téléphone, rôle)
  • ✅ Indicateur de statut en ligne/hors ligne
  • ✅ Barre de recherche avec filtres multiples
  • ✅ Boutons pour créer, modifier et supprimer des utilisateurs
  • ✅ Utilisation de l'API getByCriteria pour la récupération des données
  • ✅ Support des rôles : super, admin, recruiter

🚀 Comment tester

  1. Démarrer l'application Angular : ng serve
  2. Se connecter avec un utilisateur ayant le rôle "super"
  3. Naviguer vers /dashboard/entities#users
  4. Vérifier la redirection automatique vers /dashboard/users
  5. Tester les fonctionnalités CRUD (créer, modifier, supprimer)
  6. Tester la recherche et les filtres
