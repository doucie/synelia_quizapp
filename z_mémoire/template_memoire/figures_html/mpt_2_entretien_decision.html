MPT 2/2 – Planifier un entretien, décider & auditer

Modèle Physique des Traitements. E=Événement, CT=Contrôleur, SV=Service, RP=Repository, DB=SGBD, EXT=Externe, R=Résultat.

Déclencheur
  • ERound INTERVIEW ouvert
  • Recruteur planifie
IHM Angular
  • PgInterviewSchedulerComponent
  • Formulaire date/type/lieu
  • Sélection participants
Contrôleur REST
  • CTInterviewController
  • POST /api/interviews
  • PUT /api/interviews/{id}
Service métier
  • SVInterviewService
  • scheduleInterview(progId, dto)
  • Crée interview + candidate_interview
  • Affecte interview_participant
  • Notifie candidat (règle ON_INTERVIEW_PLANNED)
Couche d'accès
  • RPInterviewRepository
  • CandidateInterviewRepository
  • InterviewParticipantRepository
  • NotificationRuleRepository
SGBD MySQL
  • DBINSERT interviews
  • INSERT candidate_interview
  • INSERT interview_participant
  • INSERT mail_log
Externe
  • EXTSMTP → mail convocation
  • Notification in-app
Résultats émis
  • REntretien planifié → mail candidat + notif participants
  • Candidat accepte → mise à jour response_status
  • Candidat refuse → round annulé, abandon
  • Candidat propose alternative → reschedule, notif recruteur
Déclencheur
  • ERound DECISION ouvert
  • Recruteur saisit décision
IHM Angular
  • PgDecisionPanelComponent
  • Sélection type décision
  • Justification obligatoire si annulation
Contrôleur REST
  • CTDecisionController
  • POST /api/decisions
  • PUT /api/decisions/{id}/cancel
Service métier
  • SVDecisionService
  • createDecision(progId, dto)
  • cancelDecision(decisionId, justification)
  • Valide progress → recalcule current_progress_id
  • Vérifie requires_manual_confirmation
SGBD MySQL
  • DBINSERT decisions
  • UPDATE application_progress
  • UPDATE applications.current_*
  • INSERT audit_event (DECIDE)
  • INSERT mail_log (si confirmation requise)
Externe
  • EXTSMTP → mail final
  • Notification in-app
Résultats émis
  • RRound suivant ouvert → nouvelle ligne application_progress
  • Candidature finalisée RECRUTE/NON_RETENU → mail final
  • Mail en attente → recruteur doit confirmer envoi
  • Annulation → CANCEL/ROLLBACK + réouverture round
