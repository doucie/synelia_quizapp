Schéma MySQL 8 cible (post-migration 420). Colonnes d'audit communes (created_at, created_by, updated_at, updated_by, is_deleted, search_string) factorisées dans la note.

Table pivot Nouvelle table Type MySQL

Convention MPD : toutes les tables portent en plus les colonnes id (int unsigned PK AUTO_INCREMENT), created_at datetime, created_by int, updated_at datetime, updated_by int, is_deleted bit(1), search_string text. Les FK sont contraintes ON DELETE RESTRICT sauf mention contraire.
