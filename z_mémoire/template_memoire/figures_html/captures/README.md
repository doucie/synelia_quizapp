# Captures des figures Merise

Place dans ce dossier les captures (PNG, JPG) prises depuis les pages HTML voisines :

- `mcd.png` issue de [../mcd.html](../mcd.html)
- `mld.png` issue de [../mld.html](../mld.html)
- `mpd.png` issue de [../mpd.html](../mpd.html)
- `sat.png` issue de [../sat.html](../sat.html)
- `mct.png` issue de [../mct.html](../mct.html)

Conseils de capture :
- ouvre la page dans le navigateur en zoom 100 %
- masque la barre de défilement si elle gêne
- prends une capture plein cadre du diagramme (sans le header de page)
- enregistre en PNG pour préserver les traits fins des relations
