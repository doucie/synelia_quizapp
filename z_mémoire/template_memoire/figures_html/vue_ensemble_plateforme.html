SyneliaQuizApp — Vue d'ensemble de la plateforme

Plateforme unifiée de recrutement — de la diffusion de l'offre à la décision finale
Mémoire de fin d'études · ENSIT · 2026
1
Contexte & Problématique
  • Processus de recrutement éclaté sur 5 à 7 outils (emails, Excel, formulaires externes)
  • Absence de standardisation : chaque recruteur évalue avec ses propres critères
  • Aucune traçabilité décisionnelle — impossible de justifier un refus ou une sélection
2
Architecture technique
  • Frontend : Angular 20.2 · TypeScript 5.9 · SCSS · PWA responsive
  • Backend : Spring Boot 3.5.6 · Java 21 · API REST documentée (OpenAPI)
  • Persistance : JPA / Hibernate 6 · MySQL 8 · Flyway (69 migrations)
  • Sécurité : JWT · Spring Security · RBAC 4 niveaux · Audit intégral
3
Infrastructure & Services
  • Cache & sessions : Redis 7 · rate limiting · tokens distribués
  • Stockage : MinIO (S3-compatible) · uploads sécurisés
  • Emails : Thymeleaf templates · SMTP · logs de délivrabilité
  • Déploiement : Docker Compose · conteneurs isolés · CI/CD prêt
4
Modules fonctionnels
  • Campagnes : création, diffusion, pages publiques personnalisables
  • Candidatures : soumission, vérification email, suivi du pipeline
  • Quiz : QCM & texte libre, temps limité, correction automatique
  • Entretiens : planification, grille d'évaluation multi-critères
  • Décisions : workflow structuré, justification, rollback super admin
5
Gouvernance & Sécurité
  • 4 rôles : Candidat · Recruteur · Admin Métier · Super Admin
  • Permissions : RBAC par entité (campagnes, quiz, décisions…)
  • Audit : chaque action sensible loguée (entité, acteur, delta JSON)
  • Conformité : RGPD · droit d'accès · suppression des données
6
Bénéfices attendus
  • Centralisation : un seul outil pour tout le cycle de recrutement
  • Standardisation : grilles communes, scoring objectif, équité
  • Traçabilité : historique complet de chaque candidature
  • Réduction des coûts : ~1 200 €/an vs ~6 000 € (Workable)
