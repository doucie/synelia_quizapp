Carte des endpoints de l'API REST

Arborescence complète des ressources exposées par SyneliaQuizApp

/api
├─ auth/
POST /login, /register, /verify-email, /forgot-password
GET /me, /refresh-token
├─ campaigns/
GET / (liste), /{id}, /public/{slug}
POST / (créer)
PUT /{id}
├─ applications/
GET /, /{id}, /my-applications
POST / (postuler), /{id}/advance
├─ quiz/
GET /attempts/{id}, /questions
POST /start, /submit-answer, /submit-all
├─ interviews/
GET /, /{id}, /slots
POST /schedule, /{id}/evaluate
├─ evaluations/
GET /{id}, /criteria
POST /, /{id}/items
├─ decisions/
GET /{applicationId}
POST / (rendre une décision)
└─ admin/
GET /users, /roles, /audit-logs, /stats
PUT /users/{id}/roles, /settings
DELETE /users/{id}
