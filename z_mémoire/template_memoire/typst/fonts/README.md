# Embedded fonts for Typst

This directory contains the fonts used by the memoir Typst template.

Families:
- Crimson Pro
- Source Sans 3

Source:
- https://github.com/google/fonts/tree/main/ofl/crimsonpro
- https://github.com/google/fonts/tree/main/ofl/sourcesans3

License:
- SIL Open Font License (OFL)
- Full license texts are included as `CrimsonPro-OFL.txt` and `SourceSans3-OFL.txt`

Workspace integration:
- VS Code workspace setting `tinymist.fontPaths` points to this directory.
- After changing fonts or font settings, restart the Tinymist language server or reload the VS Code window.
