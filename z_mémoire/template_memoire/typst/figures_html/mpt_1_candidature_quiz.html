MPT 1/2 – Soumettre une candidature & passer le quiz

Modèle Physique des Traitements. Vue implémentation : composants Angular, contrôleurs Spring, services, repositories, SGBD.

Déclencheur
  • ELien campagne ouvert
  • Candidat saisit le formulaire
IHM Angular
  • PgApplyPositionComponent
  • Formulaire réactif
  • Upload CV (MinIO)
  • Vérification email (code 6 chiffres)
Contrôleur REST
  • CTPublicApplicationController
  • POST /api/public/apply
  • POST /api/public/verify-email
  • DTO: ApplyRequest, VerifyRequest
Service métier
  • SVApplicationService
  • createApplication(dto)
  • Vérifie max_apply campagne
  • Résout pipeline_template
  • Crée application_progress[0]
Couche d'accès
  • RPApplicationRepository
  • ApplicationProgressRepository
  • CampaignRepository.findById()
  • SourceTokenRepository
SGBD MySQL
  • DBINSERT applications
  • INSERT application_progress
  • UPDATE campaign max_apply
  • INSERT audit_event (CREATE)
Résultats émis
  • RCandidature créée → mail accusé + notification recruteur
  • ou Quota atteint → 409, audit REJECT
  • ou Token invalide → 403, audit SECURITY
Déclencheur
  • ERound QUIZ ouvert
  • Candidat ouvre /quiz/{token}
IHM Angular
  • PgQuizComponent
  • Affichage question par question
  • Timer chronométré
  • Sauvegarde auto des réponses
Contrôleur REST
  • CTPublicQuizController
  • GET /api/public/quiz/{token}
  • POST /api/public/quiz/answer
  • POST /api/public/quiz/submit
Service métier
  • SVQuizAttemptService
  • createAttempt(token, formVersion)
  • saveAnswer(attemptId, questionId, value)
  • computeScore() → screening
Couche d'accès
  • RPQuizAttemptRepository
  • CandidateAnswerRepository
  • FormVersionRepository
  • QuestionRepository
SGBD MySQL
  • DBINSERT quiz_attempt
  • INSERT candidate_answer × N
  • UPDATE aggregated_quiz_score
  • INSERT audit_event (SUBMIT)
Résultats émis
  • RRéussi auto → round validé, progression round suivant, notification
  • À corriger → attente correction manuelle, notification évaluateur
  • Échec sous seuil → round refusé, candidature éliminée, mail ON_QUIZ_FAILED
