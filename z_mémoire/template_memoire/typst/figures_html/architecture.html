Architecture applicative en couches

Vue logique de SyneliaQuizApp : du navigateur jusqu'à la base MySQL 8, en passant par le frontend Angular, l'API REST Spring Boot, les services métier et la couche de persistance JPA. Les services auxiliaires (SMTP, MinIO, Redis) sont mobilisés ponctuellement par les services métier.

Acteur / Navigateur Frontend Angular Backend Spring Boot Persistance MySQL Services auxiliaires
Acteurs Utilisateurs et navigateur web
Candidat
Parcours public : candidature, vérification d'email, quiz, suivi.
Recruteur / Évaluateur
Pilotage des campagnes, entretiens, évaluations, décisions.
Administrateur
Référentiels, utilisateurs, permissions, paramétrage.
Super administrateur
Gouvernance globale, SMTP, supervision transverse.
Couche 1 — Présentation Frontend Angular (TypeScript) — proxy de dev sur /api
Pages publiques candidat
Candidature, vérification, quiz, suivi, réponse entretien.
Espace recruteur
Campagnes, candidatures, formulaires, entretiens, évaluations, décisions.
Espace administration
Utilisateurs, rôles, permissions, référentiels, templates d'email, SMTP.
Composants & filtres partagés
Listes, formulaires réactifs, dialogues, gardes de route, intercepteurs HTTP.
Services HTTP
Appels REST typés, gestion JWT, gestion d'erreurs, état applicatif.
Couche 2 — Application Contrôleurs REST Spring Boot — DTO, validations, sécurité
API publique candidat
/api/public/** : candidature, vérification, quiz, suivi.
API campagnes et pipeline
CRUD campagnes, partage, sources, étapes de pipeline.
API formulaires et quiz
Formulaires, versions, questions, corrections, scores.
API entretiens et décisions
Planification, réponse candidat, évaluations, décisions.
API administration
Utilisateurs, permissions, référentiels, templates, SMTP.
Couche 3 — Métier Services Spring : règles de gestion, transitions de pipeline, permissions
Service Campagne
Cycle de vie, ouverture/fermeture, partage collaboratif, diffusion.
Service Candidature
Création, vérification d'email, suivi public, transitions application_progress.
Service Quiz
Tentatives, versionnement de formulaire, calcul de score, correction manuelle.
Service Entretien / Décision
Convocations, évaluations collaboratives, décisions historisées.
Service Sécurité & Permissions
Rôles système, entity_permission, campaign_crud, user_permission_override.
Service Notification
Templates d'email, notifications internes, déclencheurs métier.
Service Audit & Référentiels
Journalisation audit_event, gestion des départements, spécialités, questions, réponses.
Couche 4 — Persistance Spring Data JPA / Hibernate — entités, repositories
Entités JPA
Campaign, Application, Form, FormVersion, Question, Interview, Decision, etc.
Repositories Spring Data
Requêtes par méthode, JPQL, specifications pour les recherches dynamiques.
Transactions & intégrité
Gestion @Transactional, contraintes FK, validations métier.
Couche 5 — Stockage Base relationnelle MySQL 8 — migrations versionnées Flyway
MySQL 8 — Schéma quizapp
Tables, vues, index, contraintes FK ; pivots campaigns et applications.
Flyway
Migrations V***__*.sql versionnées, dont l'évolution 420-evolution-pipeline-multi-occurrences.
Services auxiliaires Mobilisés ponctuellement par la couche métier
SMTP
Envoi des emails : vérification, convocation, notifications candidat et recruteur.
MinIO
Stockage objet pour les pièces jointes (CV, lettres, justificatifs).
Redis
Cache et limitation de débit sur certains points d'entrée publics.
