MPD 3 – Candidature, avancement & quiz

Modèle physique MySQL. PK soulignée, FK en #, NN = NOT NULL.

CANDIDATURE
  • PKIdCandidature INT UNSIGNED
  • #IdCampagne INT UNSIGNED NN
  • #IdSource INT UNSIGNED
  • #IdFormVersion INT UNSIGNED
  • Nom VARCHAR(100) NN
  • Prenom VARCHAR(100) NN
  • Email VARCHAR(255) NN
  • Telephone VARCHAR(20)
  • CvPath VARCHAR(1000)
  • LettreMotivation TEXT
  • EmailVerified TINYINT(1) NN
  • EstAbandonnee TINYINT(1)
  • AbandonReason TEXT
  • AggQuizScore DOUBLE
  • AggEvalScore DOUBLE
AVANCEMENT
  • PKIdAvancement INT UNSIGNED
  • #IdCandidature INT UNSIGNED NN
  • #IdEtape INT UNSIGNED NN
  • ProgressStatus VARCHAR(20) NN
  • DateDebut DATETIME
  • DateFin DATETIME
  • Score DOUBLE
  • Notes TEXT
  • #ValidatedBy INT UNSIGNED
  • DateValidation DATETIME
  • #SkippedBy INT UNSIGNED
  • SkipReason TEXT
TENTATIVE_QUIZ
  • PKIdTentative INT UNSIGNED
  • #IdAvancement INT UNSIGNED NN
  • #IdVersion INT UNSIGNED NN
  • TokenQuiz VARCHAR(255) NN
  • QuizStatus VARCHAR(20) NN
  • ScreeningMode VARCHAR(50)
  • Score DOUBLE
  • ScorePercent DOUBLE
  • TimeElapsed BIGINT
REPONSE_CANDIDAT
  • PKIdReponseCandidat INT UNSIGNED
  • #IdTentative INT UNSIGNED NN
  • #IdQuestion INT UNSIGNED NN
  • #IdReponse INT UNSIGNED
  • EstSelectionnee TINYINT(1) NN
  • TexteLibre TEXT
  • CorrectionManuelle TINYINT(1)
  • #CorrectedBy INT UNSIGNED
DECISION
  • PKIdDecision INT UNSIGNED
  • #IdAvancement INT UNSIGNED NN
  • #IdUtilisateur INT UNSIGNED
  • TypeDecision VARCHAR(50) NN
  • Justification TEXT
  • ModeDecision VARCHAR(20) NN
  • #CancelsDecisionId INT UNSIGNED
DEMANDE_CANDIDAT
  • PKIdDemande INT UNSIGNED
  • #IdCandidature INT UNSIGNED NN
  • TypeDemande VARCHAR(50) NN
  • Statut VARCHAR(30) NN
  • NouveauNom VARCHAR(100)
  • NouveauPrenom VARCHAR(100)
  • NouvelEmail VARCHAR(255)
