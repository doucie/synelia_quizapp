MPD 1 – Identité, groupes & permissions

Modèle physique MySQL. PK soulignée, FK en #, types SQL.

UTILISATEUR
  • PKIdUtilisateur INT UNSIGNED
  • Nom VARCHAR(100) NN
  • Prenom VARCHAR(100) NN
  • Email VARCHAR(255) NN
  • Username VARCHAR(100) NN
  • RoleSysteme VARCHAR(50) NN
  • EstActif TINYINT(1) NN
GROUPE_METIER
  • PKIdGroupe INT UNSIGNED
  • Libelle VARCHAR(255) NN
  • Description TEXT
PERMISSION_ENTITE
  • PKIdPermission INT UNSIGNED
  • TypeEntite VARCHAR(100) NN
  • IdEntite INT UNSIGNED NN
  • ClePermission VARCHAR(100) NN
USER_BUSINESS_GROUP
  • PF#IdUtilisateur INT UNSIGNED
  • PF#IdGroupe INT UNSIGNED
BUSINESS_GROUP_PERMISSION
  • PF#IdGroupe INT UNSIGNED
  • PF#IdPermission INT UNSIGNED
USER_PERMISSION_OVERRIDE
  • PF#IdUtilisateur INT UNSIGNED
  • PF#IdPermission INT UNSIGNED

Figure — MPD du sous-domaine Identité & Permissions. PK = clé primaire, PF = clé primaire étrangère, NN = NOT NULL.
