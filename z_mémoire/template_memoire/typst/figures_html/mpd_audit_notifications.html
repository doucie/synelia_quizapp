MPD 5 – Notifications, mails & audit

Modèle physique MySQL. PK soulignée, FK en #, NN = NOT NULL.

NOTIFICATION
  • PKIdNotification INT UNSIGNED
  • #IdUtilisateur INT UNSIGNED NN
  • Type VARCHAR(50) NN
  • Lien VARCHAR(500)
  • EstLue TINYINT(1) NN
  • TypeEntite VARCHAR(100) NN
  • IdEntite INT UNSIGNED NN
MAIL_LOG
  • PKIdMail INT UNSIGNED
  • #IdRegle INT UNSIGNED
  • #IdAvancement INT UNSIGNED
  • #IdEntretien INT UNSIGNED
  • #IdDecision INT UNSIGNED
  • Destinataire VARCHAR(255) NN
  • Sujet VARCHAR(500) NN
  • Statut VARCHAR(50) NN
  • CodeEvenement VARCHAR(100) NN
  • ConfirmationRequise BIT(1) NN
  • #ConfirmedBy INT UNSIGNED
  • DateConfirmation DATETIME
EVENEMENT_AUDIT
  • PKIdEvenement INT UNSIGNED
  • #IdUtilisateur INT UNSIGNED
  • TypeEntite VARCHAR(100) NN
  • IdEntite INT UNSIGNED NN
  • TypeAction VARCHAR(100) NN
  • Acteur VARCHAR(255)
  • Justification TEXT
  • BeforeJson TEXT
  • AfterJson TEXT
