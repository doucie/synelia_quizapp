Recruteur ─── POST /api/applications/142/advance ───▶ Controller
Controller ─── advanceApplication(id, nextStage) ───▶ PipelineBusiness
1. Valide l'étape actuelle
2. Résout l'étape suivante (stage_order + 1)
3. Vérifie les conditions de transition
PipelineBusiness ─── findById(applicationId) ───▶ Database
PipelineBusiness ─── save(applicationProgress) ───▶ Database
4. Met à jour application_progress (nouveau statut)
5. Émet ApplicationAdvancedEvent → notifications
Database ◀─── ApplicationProgress (mis à jour) ─── PipelineBusiness
PipelineBusiness ◀─── DTO (nouveau statut, étape) ─── Controller
Controller ◀─── HTTP 200 + ApplicationDTO ─── Recruteur
