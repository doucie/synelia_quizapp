Diagrammes de séquence — scénarios majeurs

Quatre scénarios représentatifs du fonctionnement de SyneliaQuizApp : candidature publique, passation du quiz, planification d'entretien, prise de décision finale. Les flèches pleines représentent les appels synchrones, les pointillés les retours et événements asynchrones.

Acteur humain Frontend Angular API / Service Spring Base MySQL Service auxiliaire

1. Soumission d'une candidature publique

Candidat
Angular (public)
API /api/public
ApplicationService
MySQL
SMTP
ouvre le lien de campagne
GET /campaigns/{token}
SELECT campaign + sourceToken
contexte campagne valide
payload campagne
remplit le formulaire + soumet
POST /applications
creerCandidature(dto)
INSERT applications + progress[0]
envoyer email de vérification
accusé + code de suivi
Toute soumission est rate-limitée et passe par une double vérification d'email (lien à usage unique).
